# NSL Writer Tools

แอป **World Bible** สำหรับนักเขียนนิยาย ใช้เก็บและเชื่อมโยงข้อมูลโลกในเรื่อง ทั้งตัวละคร สถานที่ องค์กร เหตุการณ์ ไอเทม กฎของโลก และสปีชีส์ พัฒนาด้วย Flutter โค้ดชุดเดียวใช้ได้ทั้ง Windows และ Android หน้าจอทั้งหมดเป็นภาษาไทย

## ฟีเจอร์

- **รายการ (Entry)** แบ่งเป็น 7 ประเภท พร้อมสถานะ แท็ก และรูปปก 1 รูปต่อรายการ
- **ลิงก์แบบ `[[ชื่อ]]`** พร้อมเติมอัตโนมัติ, backlinks, รองรับชื่อแฝง และเมื่อเปลี่ยนชื่อรายการ ลิงก์ที่อ้างถึงจะถูกแก้ตามให้อัตโนมัติ
- **ค้นหาและกรอง** ตามสถานะและแท็ก เรียงตามแก้ไขล่าสุดหรือเรียงตามตัวอักษรไทย
- **หลายโลก (World)** สลับ สร้าง เปลี่ยนชื่อ และลบได้ พร้อมแดชบอร์ดแสดงจำนวนรายการ รายการกำพร้า และลิงก์เสีย
- **ไทม์ไลน์** ใช้ปฏิทินของโลกที่กำหนดเองได้ รองรับวันที่แบบไม่ระบุเดือนหรือวัน ช่วงเวลา และผู้เกี่ยวข้อง
- **กราฟความสัมพันธ์** จัดวางแบบ force-directed ซูมและเลื่อนได้ ลากโหนดได้ กรองตามประเภทความสัมพันธ์ และโฟกัสที่รายการเดียวได้
- **ซิงก์ระหว่างเครื่อง (PC ↔ Android)** ไม่ต้องมีเซิร์ฟเวอร์ ส่งผ่านไฟล์หรือผ่าน Wi-Fi เดียวกัน เมื่อแก้ไขขัดกันจะเก็บฉบับที่แพ้ไว้เป็นสำเนา "(ขัดแย้ง)"
- **สำรองข้อมูล** ส่งออกและนำเข้า JSON (นำเข้าจะสร้างโลกใหม่เสมอ ไม่เขียนทับของเดิม), ส่งออก Markdown และสำรองอัตโนมัติทุกครั้งที่เปิดแอป โดยเก็บล่าสุด 10 ชุดต่อโลก
- **ธีม** สว่าง กลางคืน หรือตามระบบ และฟอนต์ไทยที่แถมมาในแอป (Noto Serif Thai, IBM Plex Sans Thai, IBM Plex Mono) ใช้งานออฟไลน์ได้

## หลักการออกแบบ

- ลิงก์อ้างอิงด้วย **ชื่อ** ดังนั้นชื่อรายการต้องไม่ซ้ำกันภายในโลกเดียวกัน
- ทำงานแบบออฟไลน์เป็นหลัก ไม่ต้องมีบัญชีหรือเซิร์ฟเวอร์ การซิงก์คือการรวมข้อมูลสองฝั่ง ไม่ใช่การเชื่อมต่อสด
- การค้นหาเป็นแบบหาข้อความตรงๆ (ภาษาไทยไม่มีช่องว่างระหว่างคำ)
- การสำรองข้อมูลไม่เขียนทับ ส่วนการซิงก์จะรวมเข้าโลกเดิมตาม id

## วิธีรัน

ต้องติดตั้ง [Flutter SDK](https://docs.flutter.dev/get-started/install) ก่อน

```
flutter pub get
flutter run -d windows        # รันบนพีซี
flutter run                   # รันบนมือถือ Android หรือ emulator ที่เชื่อมต่ออยู่
flutter test                  # รันเทสต์
```

## วิธีสร้างไฟล์ติดตั้ง

```
flutter build windows --release
# ได้ไฟล์ที่ build\windows\x64\runner\Release\nsl_writer_tools.exe

flutter build apk --release
# ได้ไฟล์ที่ build\app\outputs\flutter-apk\app-release.apk
```

APK ที่สร้างตอนนี้เซ็นด้วยคีย์ดีบัก เหมาะสำหรับติดตั้งเองบนเครื่อง ยังใช้ส่งขึ้น Play Store ไม่ได้

## ข้อจำกัดที่ควรรู้

- การซิงก์เชื่อถือเวลาของเครื่อง ถ้านาฬิกาผิดมาก ฉบับที่ถูกเลือกอาจผิดไป (แต่ข้อความยังถูกเก็บไว้เป็นสำเนา)
- การซิงก์ผ่าน Wi-Fi **ไม่ได้เข้ารหัส** (มีแค่ลายเซ็นยืนยัน) ควรใช้ในเครือข่ายที่ไว้ใจได้เท่านั้น
- ปฏิทินของโลกใช้ตั้งชื่ออย่างเดียว ยังไม่คำนวณความยาวเดือน ปีอธิกสุรทิน หรือบวกลบวันที่
- ตำแหน่งโหนดในกราฟไม่ถูกบันทึกลงฐานข้อมูล
- ตัวแก้ไขยังไม่มีปุ่มตัวหนา ตัวเอียง และ `#tag` และเนื้อหายังไม่ถูกแสดงผลเป็น Markdown
- การส่งออก Markdown ยังไม่รวมวันที่บนไทม์ไลน์
